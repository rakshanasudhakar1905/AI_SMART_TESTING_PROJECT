# AI-Based Smart Software Testing and Quality Assurance Platform

## Project Description

The AI-Based Smart Software Testing and Quality Assurance Platform is designed to automate software testing and support intelligent quality assurance.

The system contains four major modules:

1. Intelligent Test Case Generation
2. Automated Test Execution and Monitoring
3. Defect Prediction and Analysis
4. Quality Assurance Dashboard and Reporting

## How to Run Without Docker

Install dependencies:

pip install -r requirements.txt

Run:

python app.py

Open:

http://localhost:5000

## How to Run Using Docker

Build and start the container:

docker compose up --build

Open:

http://localhost:5000

## Project Modules

### Module 1

Generates positive, negative, edge and boundary test cases from software requirements.

### Module 2

Automatically executes PyTest test cases and displays pass, fail and error results.

### Module 3

Uses a Random Forest machine learning model to predict software defect risk.

### Module 4

Displays testing metrics, defect risk and quality information through a dashboard.
